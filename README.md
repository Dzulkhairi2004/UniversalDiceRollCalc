# Universal Dice Roll Calculator

A Java-based TTRPG dice rolling engine supporting digital random generation and physical die tracking.

## Phase 1 Features
- Core dice expression parser (`d4`, `d6`, `d8`, `d10`, `d12`, `d20`, `d100`).
- Digital roller for automated random rolls.
- Physical roller prompt for manual die result inputs.
- Interactive CLI loop (`MainApp`).

## Roadmap
- **Phase 2:** Advanced modifiers, advantage/disadvantage logic, and roll history logging.
